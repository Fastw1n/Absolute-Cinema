# AbsoluteCinema — учебная версия dev

Приложение на SwiftUI с MVVM, SwiftData и UserDefaults. Минимальная версия — iOS 17.
Откройте AbsoluteCinema.xcodeproj, выберите схему AbsoluteCinema и запустите на симуляторе.
Ключи API и подключение к интернету не нужны.

## Что умеет приложение

- Поиск по русскому или оригинальному названию в локальном массиве из четырёх фильмов.
- Карточка с описанием, оценкой от 1 до 10 и необязательным комментарием.
- Сохранение, чтение, редактирование и удаление личной оценки вместе с комментарием.
- «Мои оценки»: постер, название, год, демонстрационный рейтинг TMDB и ваша оценка справа.
- Сортировка по дате выставления оценки либо по вашей оценке, от большей к меньшей.

Данные фильмов вручную заполнены в AbsoluteCinema/Data/MockMovies.swift.
Рейтинги TMDB — фиксированные демонстрационные значения. Это не актуальные данные API.
Постер «Космической одиссеи» находится в Assets; у остальных моков отображается заглушка.

## Как устроен код

- Models/Movie.swift — обычная структура с информацией о фильме.
- Data/MockMovies.swift — локальные фильмы.
- Data/Repositories/MovieRepository.swift — поиск и получение фильма из массива.
- Data/Persistence/RatedMovie.swift — сохраняемая модель SwiftData.
- Data/Repositories/RatingRepository.swift — все CRUD-операции со SwiftData.
- Data/Persistence/SettingsStore.swift — настройка сортировки в UserDefaults.
- Features — три экрана, у каждого свой View и ViewModel.
- Shared/MoviePoster.swift — общий постер со скруглением и строка результата поиска.
- AbsoluteCinemaApp.swift — запуск, общее хранилище, вкладки и переходы в карточку.

View описывает расположение элементов и передаёт действия во ViewModel.
ViewModel содержит состояние экрана и вызывает репозиторий.
Репозиторий получает данные из массива или SwiftData. View не работает с базой напрямую.
@Observable даёт SwiftUI возможность отслеживать изменения ViewModel, а @State сохраняет
сам экземпляр ViewModel при перерисовке экрана. Привязка $viewModel.comment связывает поле ввода
со свойством ViewModel в обе стороны.

## Почему два хранилища

SwiftData сохраняет записи об оценённых фильмах: информацию о фильме, личную оценку,
комментарий и дату. Эти записи нужны после перезапуска; их можно прочитать, изменить,
удалить и отсортировать. Для одного ID фильма создаётся одна запись.

UserDefaults сохраняет небольшой параметр — выбранный способ сортировки.
При следующем запуске пользователь увидит привычный порядок фильмов.

В карточке выбор оценки и ввод комментария ещё не сохраняют запись. Это делает кнопка
«Сохранить оценку». При редактировании числовой оценки дата обновляется; при изменении
только комментария остаётся прежней. Удаление доступно в карточке и свайпом в списке.

## Ветки и данные

Предыдущая версия с настоящим API сохранена в main (коммит 991b30a).
В dev сетевых вызовов нет. Игнорируемый локальный TMDBConfig.plist оставлен для main,
но исключён из сборки dev.
Для dev используется отдельная база DevRatings и ключ dev.ratings.sortOrder.
Поэтому список сначала может быть пустым; оценки предыдущей версии не удаляются.

Для текущих изменений достаточно проверки сборки и одного UI-теста запуска
AbsoluteCinemaUITests/testAppLaunchesAndOpensRatings. Полный набор тестов хранения
можно запускать отдельно, но при этой доработке он не прогоняется.
