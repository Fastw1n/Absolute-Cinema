# Аудит локального прототипа

8 октября 2026 года. Проверяется текущая рабочая копия dev, включая незакоммиченные изменения.

## Соответствие требованиям

| Требование | Текущее состояние |
| --- | --- |
| SwiftUI, iOS 17+ | Сохранены; приложение собрано для iOS Simulator |
| Простой MVVM | Поиск, карточка, оценки и желаемое имеют ViewModel; View не обращаются к SwiftData или UserDefaults |
| Минимум четыре экрана | Поиск, карточка, мои оценки, хочу посмотреть; отдельно форма оценки |
| Хранение | SwiftData: оценки и желаемое; UserDefaults: сортировка |
| Работа с сетью | Отложена по уточнению разработчика; четыре мока остаются источником фильмов |
| Многопоточность | Не реализована; способ демонстрации ожидает уточнения по занятию |
| Unit-тесты | Работа с ними отложена по прямому указанию разработчика |

## Что изменилось

- У поиска появилась небольшая SearchViewModel с фильтрацией по русскому и оригинальному названию.
- «Оценить» открывает форму: черновик сохраняется только кнопкой, закрытие формы отменяет несохранённые изменения.
- Желаемые фильмы сохраняются без обязательной оценки, в отдельной модели и репозитории.
- Личная оценка и желаемое независимы; данные прежних оценок не преобразовывались в новую модель.
- Навигация передаёт Movie из списка, а не повторно ищет ID в MockMovies. Сохранённая карточка больше не зависит от массива моков.
- ViewModel списка оценок имеет одного владельца; View получает сортировку через ViewModel; удаление не вызывает второе ручное чтение поверх revision.

- Поиск по русскому фрагменту и оригинальному названию в верхнем регистре показал соответствующий фильм; для отсутствующего названия показано пустое состояние.

## Результат аудита

Ручная проверка согласованного локального этапа завершена. Повторный независимый статический аудит субагентом не обнаружил существенных регрессий или причин добавлять архитектурные слои.
Сеть и демонстрация многопоточности остаются незакрытыми требованиями итогового приложения, отложенными до следующих этапов.

## Границы проверки

Самый старый установленный runtime — iOS 26.5. Deployment target остаётся iOS 17, но запуск на iOS 17 не проверен.
Тестовые targets не изменялись и не запускались в этой задаче. Ошибки диска и отказ записи искусственно не вызывались.
README отсутствовал в рабочем дереве до реализации; его удаление сохранено, ссылка из AGENTS.md заменена актуальным описанием этапа.

Архитектура остаётся прямой: View → ViewModel → конкретный репозиторий. Два сохраняемых класса содержат снимок фильма; это сознательное повторение полей для простого независимого хранения, без дополнительного универсального слоя.
Для локального прототипа работа SwiftData на MainActor допустима при текущем объёме. Подключение сети и пример конкурентной работы остаются отдельными следующими этапами.
