# Текущий этап

Согласовано с разработчиком 8 октября 2026 года. Обновлять этот документ при смене этапа.

## Что делаем сейчас

Доводим локальный прототип на моках: простой MVVM, четыре экрана, оценка и список «Хочу посмотреть».
После изменений проверяем SwiftData и UserDefaults вручную, затем проводим аудит текущего состояния.
Разработчик отдельно подтвердил, что подключение TMDB относится к следующему этапу.
Тема ближайшего занятия — виды многопоточности в Swift. Разработчик позже уточнит, какой механизм ожидается преподавателем.

Тесты временно отложены по прямому указанию разработчика: не добавлять, не менять и не запускать их до его отдельного сообщения о возвращении к этой теме.
Историческое указание README о запуске одного UI-теста к текущему этапу не применяется.

## Что реализовано

Сохраняем SwiftUI, SwiftData, iOS 17+ и простой MVVM. Карточка содержит кнопки «Оценить» и «Хочу посмотреть».
Разработчик уже понимает устройство карточки на моках; следующие изменения следует объяснять через знакомый экран и конкретный путь данных.

Четыре экрана: поиск, карточка, «Мои оценки», «Хочу посмотреть». Форма оценки открывается отдельным sheet из карточки.
Поиск фильтрует четыре мока по русскому или оригинальному названию в SearchViewModel.
Карточка, поиск и оба списка имеют ViewModel; в дочерних списках нет повторного @State для одного экземпляра ViewModel.

SwiftData хранит оценки с комментариями в RatedMovie и желаемые фильмы в WatchlistMovie, в одной базе DevRatings.
Отдельная модель желаемого позволяет сохранить фильм без оценки и сохранить существующие записи RatedMovie без изменения их полей.
Оценка и желаемое независимы: удаление одного не удаляет другое; автоматического удаления из желаемого после оценки нет.
Одна запись каждого вида соответствует одному ID фильма. Списки передают в карточку сохранённый Movie, без поиска в MockMovies.

Ввод в форме — черновик. «Сохранить оценку» записывает его в базу; отмена или закрытие sheet возвращает сохранённое состояние.
Оценка ограничена диапазоном 1–10. Изменение только комментария сохраняет дату, изменение числа обновляет её.
UserDefaults сохраняет сортировку оценок: сначала новые или сначала высокая личная оценка, через ключ dev.ratings.sortOrder.
Общие репозитории создаются в App; обновление списков после записи связано с revision и onAppear.

## Открытые решения

- Уточнить по итогам занятия: GCD, OperationQueue или Swift Concurrency; какой пример нужен для демонстрации.
- При подключении сети определить тип имеющегося credential: API Key или API Read Access Token. Значение в чат и документацию не переносить.

Общие требования к итоговой сдаче остаются: сеть, хранение, минимум четыре экрана, MVVM, unit-тесты и многопоточность.
Текущий этап не означает, что все эти требования уже выполнены.
